# DataFlow12
A small Python utility for checking and cleaning CSV datasets.

- Checks that required columns are present.
- Removes extra spaces from text fields.
- Flags missing values and duplicate records.
- Checks numeric scores for valid ranges.
- Keeps the original input file unchanged.
- Writes a cleaned CSV and quality report.

Run with `python main.py`. Built with Python's standard library and Class 12 file-handling concepts.
