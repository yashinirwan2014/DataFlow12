# DataFlow12

1. DataFlow12 is a Python project for checking and cleaning CSV files.
2. It checks whether the required columns are present.
3. It removes extra spaces from text fields.
4. It identifies missing values and duplicate records.
5. It checks whether numeric scores are within the valid range.
6. It keeps the original input file unchanged.
7. It creates a cleaned CSV file and a quality report.
8. Run the project with `python main.py`.
9. It uses Python standard library features and Class 12 file handling concepts.
